# آرکانا | Arcana Tarot

نسخه‌ی تازه‌ی پروژه‌ی GODHAND برای تجربه‌ی فارسی تاروت. این بازطراحی روی شاخه‌ی `tarot-rebuild` انجام شده و شاخه‌ی `main` و فایل‌های قبلی دست‌نخورده‌اند.

## امکانات فعلی
- رابط فارسی، راست‌چین، واکنش‌گرا با تم شبانه و طلایی
- پنج چیدمان: کارت روز، گذشته/حال/آینده، عاطفی، بله/خیر و صلیب سلتیک
- مجموعه‌ی ۷۸ کارت (۲۲ آرکانای کبیر و ۵۶ آرکانای صغیر)
- معنی، پیام تأمل و جنبه‌ی سایه برای کارت‌ها
- کارت‌های معکوس، علاقه‌مندی‌ها، جست‌وجو و فیلتر دسته‌ها
- ذخیره‌ی فال‌ها در دفتر محلی مرورگر، حذف و اشتراک‌گذاری
- بدون نیاز به نصب، دیتابیس، کلید API یا وابستگی سمت سرور

## اجرا
فایل `index.html` را باز کن یا با هر static hosting منتشر کن. `app.js` باید کنار آن باشد.

## حریم خصوصی و امنیت
- تاریخچه و علاقه‌مندی‌ها در `localStorage` همان مرورگر ذخیره می‌شوند.
- این نسخه هیچ داده‌ای به سرور ارسال نمی‌کند.
- برای قابلیت تفسیر مبتنی بر هوش مصنوعی باید بعداً یک API امن سمت سرور/Worker اضافه شود؛ کلید API هرگز نباید در کد مرورگر قرار گیرد.
- سایت برای سرگرمی و خوداندیشی است و پیش‌بینی قطعی یا مشاوره پزشکی، مالی و حقوقی ارائه نمی‌کند.

## امنیت پروژه‌ی قبلی
نسخه‌ی قدیمی در تاریخچه‌ی مخزن حاوی یک توکن ربات تلگرام بوده است. حذف آن از فایل فعلی، توکن را از تاریخچه‌ی Git پاک نمی‌کند. توکن باید از طریق BotFather باطل و جایگزین شود؛ همچنین برای پاک‌سازی کامل تاریخچه‌ی عمومی باید جداگانه تصمیم‌گیری شود.
