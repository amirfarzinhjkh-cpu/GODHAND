# آرکانا | Arcana

پلتفرم فارسی تاروت با رابط RTL، چیدمان‌های نمادین، کتابخانه کامل ۷۸ کارت، حساب کاربری و API آماده اتصال به Cloudflare.

## امکانات رابط
- تم شبانه، واکنش‌گرا و فارسی
- ۵ چیدمان: کارت روز، گذشته/حال/آینده، عاطفی، بله/خیر و صلیب سلتیک
- ۷۸ کارت: ۲۲ آرکانای کبیر و ۵۶ آرکانای صغیر
- معنی، پیام تأمل و سایه کارت؛ امکان کارت معکوس
- جست‌وجو، فیلتر دسته‌ها و علاقه‌مندی‌ها
- دفتر فال محلی و اشتراک‌گذاری
- ثبت‌نام، ورود، حذف حساب و همگام‌سازی ابری (پس از راه‌اندازی API)
- تفسیر هوشمند با Gemini (پس از ثبت Secret در Worker)
- پنل مدیریتی آمار کاربران و چیدمان‌ها
- صفحات حریم خصوصی و شرایط استفاده

## ساختار
- `index.html`, `app.js`, `account.js`: رابط و منطق مرورگر
- `worker/src/index.js`: API امن Cloudflare Worker
- `worker/migrations/0001_init.sql`: ساختار D1
- `worker/wrangler.toml`: قالب تنظیمات استقرار
- `privacy.html`, `terms.html`: صفحات حقوقی پایه
- `.github/workflows/check.yml`: بررسی نحوی فایل‌های JS

## اجرای محلی
فایل `index.html` را از طریق یک static server باز کن؛ برای نمونه:
`python -m http.server 8080`
سپس `http://localhost:8080` را باز کن. در حالت بدون Worker، فال‌گیری محلی فعال است؛ ورود، همگام‌سازی و AI به API نیاز دارند.

## راه‌اندازی بک‌اند
مراحل کامل در [worker/README.md](worker/README.md) است. قبل از انتشار باید:
1. D1 بسازی و شناسه دیتابیس را در `worker/wrangler.toml` قرار دهی.
2. migration را اجرا کنی.
3. `ALLOWED_ORIGIN` و `ADMIN_EMAIL` را تنظیم کنی.
4. کلید Gemini را فقط به‌صورت Worker Secret ثبت کنی.
5. Worker را مستقر کنی و مسیر هم‌مبدأ `/api/*` را به آن متصل کنی.
6. حساب مدیر را پس از ثبت‌نام با دستور امن D1 به نقش admin ارتقا دهی.
7. متن صفحات حقوقی را با اطلاعات واقعی مالک سایت کامل کنی.

**هیچ کلید یا رمز API نباید در فایل‌های سمت مرورگر قرار گیرد.** تا قبل از تنظیمات بالا، حساب کاربری، تفسیر AI و همگام‌سازی ابری فعال نیستند.

## امنیت
جلسه‌ها با توکن تصادفی و کوکی HttpOnly/Secure/SameSite مدیریت می‌شوند؛ دیتابیس فقط هش توکن نشست را ذخیره می‌کند. رمزها با PBKDF2-SHA-256 هش می‌شوند. برای انتشار عمومی واقعی، تأیید ایمیل، بازیابی رمز، Cloudflare Turnstile، پایش خطا، پاک‌سازی زمان‌بندی‌شده و بازبینی مستقل امنیتی توصیه می‌شود.

## توجه مهم درباره نسخه قدیمی
تاریخچه مخزن در گذشته شامل یک توکن ربات تلگرام بوده است. توکن باید در BotFather باطل و جایگزین شود. تغییر فایل‌ها در این شاخه، راز را از تاریخچه Git پاک نمی‌کند. قبل از عمومی‌سازی نهایی، تاریخچه و همه نسخه‌های پشتیبان باید جداگانه بررسی شوند.
